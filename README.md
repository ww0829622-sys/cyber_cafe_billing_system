# Cyber Cafe Billing System
## Project Description
The Cyber Cafe Billing System is a web-based application developed using Python and Flask. It helps cyber cafe operators calculate customer charges based on the number of hours a computer is used.
## Technologies Used
- Python
- Flask
- HTML
- CSS
## Features
- Customer name entry
- Computer number entry
- Recording hours of computer usage
- Automatic billing calculation
- Displaying customer billing details
## How it works
1. Enter the customer's name
2. Enter the computer number
3. Enter the number of hours used
4. The system calculates the total amount payable
5. The billing details are displayed
